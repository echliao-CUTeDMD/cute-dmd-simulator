# 中國科大數媒系・大學生生存模擬器

以中國科技大學數位多媒體設計系為背景，從大一入學模擬到大四畢業的瀏覽器遊戲。

## 在 GitHub Pages 發布

1. 建立一個 Public 公開儲存庫。
2. 將本資料夾內的 `index.html`、`.nojekyll` 與 `README.md` 上傳到儲存庫根目錄。
3. 開啟儲存庫的 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. Branch 選擇 `main`，資料夾選擇 `/ (root)`，按下 **Save**。
6. 等待約一至數分鐘，Pages 頁面會顯示可公開遊玩的網址。

遊戲進度會儲存在玩家自己的瀏覽器中，不需要伺服器或資料庫。
